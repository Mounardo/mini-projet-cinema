# Mini-projet Cinéma

Application web réalisée dans le cadre d'un mini-projet SUPINFO.

## Fonctionnalités

- Affichage de films tendances
- Chargement de films supplémentaires sortis en 2024
- Recherche de films en temps réel
- Pagination des résultats de recherche
- Affichage détaillé d'un film
- Résumé complet
- Genre et acteurs
- Note IMDb
- Date de sortie DVD
- Gestion des erreurs et des films introuvables

## Technologies utilisées

- HTML5
- CSS3
- JavaScript
- API OMDb
- Git
- GitHub

## Pages

- `index.html` : accueil et films tendances
- `search.html` : recherche de films
- `movie.html` : détails d'un film

## Lancement du projet

Le projet doit être exécuté avec un serveur HTTP local, par exemple avec l'extension **Live Server** de Visual Studio Code.

## API

Les informations sur les films proviennent de l'API OMDb.
